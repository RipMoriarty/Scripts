# РП Чат

Android-приложение для ролевых диалогов с ИИ-персонажами. Создаёте персонажа с характером, манерой речи и поведением — модель играет его и держится роли. Ответы генерирует **DeepSeek через OpenRouter** (есть бесплатные модели).

## Как получить APK

1. Откройте вкладку **Actions → Build RP Chat APK** и дождитесь зелёной галочки (≈5–8 минут). Запуск идёт автоматически после каждого коммита в `main`, затрагивающего папку `rp-chat/`; вручную — кнопкой **Run workflow**.
2. Готовый файл `RP-Chat.apk` лежит в разделе **Releases** (справа на главной странице репозитория) — скачайте его с телефона.
3. Разрешите установку из неизвестных источников для браузера/файлового менеджера и откройте файл.

APK подписан отладочным ключом: для ручной установки этого достаточно, для Google Play нужна release-подпись.

## Первый запуск

1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai) (можно через Google или GitHub) и создайте ключ на [openrouter.ai/keys](https://openrouter.ai/keys).
2. В приложении: **⚙️ Настройки** → вставьте ключ → **Проверить ключ**.
3. Нажмите **Найти бесплатные DeepSeek** и выберите модель из списка.
4. Откройте любого персонажа и пишите.

> Бесплатные модели OpenRouter (`…:free`) ограничены: 20 запросов в минуту и 50 в день на аккаунт; после разовой покупки 10 кредитов лимит поднимается до 1000 в день. Список бесплатных моделей меняется — поэтому в приложении есть поиск, а при исчезновении модели оно само подставляет другую бесплатную DeepSeek.

## Возможности

- Карточки персонажей: имя, аватар (эмодзи или картинка), описание, характер, манера речи и поведение, сценарий, первое сообщение, пример диалога, жёсткие правила. Макросы `{{char}}` и `{{user}}`.
- Чат с памятью (последние N сообщений), потоковый вывод, «Стоп», «Заново», «Продолжить», правка и удаление сообщений, откат диалога к выбранному месту, новый чат.
- Ваш персонаж в игре: имя и описание.
- Импорт карточек SillyTavern (`.json` и `.png`, форматы V1/V2/V3), экспорт и резервные копии.
- Настройки: температура, длина ответа, глубина памяти, адрес API (подойдёт любой OpenAI-совместимый, например `https://api.deepseek.com`).
- Все данные хранятся только на устройстве; ключ никуда, кроме выбранного API, не отправляется.

## Как устроено

- `www/` — само приложение (чистый HTML/CSS/JS, без сборки): `lib.js` — логика промптов и импорта, `api.js` — запросы к API, `app.js` — интерфейс.
- Capacitor оборачивает `www/` в Android-приложение. Папка `android/` не хранится в репозитории: workflow (`.github/workflows/rp-chat-apk.yml` в корне репозитория) генерирует её командой `npx cap add android`, накладывает иконки из `resources/` и собирает APK.
- `tests/` — тесты: `npm test` (логика и API-клиент на Node) и `python3 tests/ui/ui_test.py` (интерфейс в headless Chromium с подменой ответов API).

## Локальная разработка

```bash
npm test                           # юнит-тесты и тесты API-клиента
python3 -m http.server -d www 8080 # открыть http://localhost:8080 в браузере
```
