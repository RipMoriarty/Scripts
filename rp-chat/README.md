# РП Чат

Android-приложение для ролевых диалогов с ИИ-персонажами. Создаёте персонажа с характером, манерой речи и поведением — модель играет его и держится роли. Ответы генерирует **DeepSeek через OpenRouter** (есть бесплатные модели).

## Как получить APK

1. Откройте вкладку **Actions → Build RP Chat APK** и дождитесь зелёной галочки (≈5–8 минут). Запуск идёт автоматически после каждого коммита в `main`, затрагивающего папку `rp-chat/`; вручную — кнопкой **Run workflow**.
2. Готовый файл `RP-Chat.apk` лежит в разделе **Releases** (справа на главной странице репозитория) — скачайте его с телефона.
3. Разрешите установку из неизвестных источников для браузера/файлового менеджера и откройте файл.

APK подписан отладочным ключом: для ручной установки этого достаточно, для Google Play нужна release-подпись. Начиная со сборки №2 ключ подписи постоянный, так что новые версии ставятся поверх старых. Сборку №1 подписывал случайный ключ: при переходе на новую версию удалите её один раз (перед этим сделайте резервную копию в Настройках).

## Первый запуск

1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai) (можно через Google или GitHub) и создайте ключ на [openrouter.ai/keys](https://openrouter.ai/keys).
2. В приложении: **⚙️ Настройки** → вставьте ключ → **Проверить ключ**.
3. Нажмите **Найти бесплатные DeepSeek** и выберите модель из списка.
4. Откройте любого персонажа и пишите.

> Бесплатные модели OpenRouter (`…:free`) ограничены: 20 запросов в минуту и 50 в день на аккаунт; после разовой покупки 10 кредитов лимит поднимается до 1000 в день. Список бесплатных моделей меняется — поэтому в приложении есть поиск, а при исчезновении модели оно само подставляет другую бесплатную DeepSeek.

## Свой сервер вместо OpenRouter (без лимитов и ключа)

Приложение умеет работать с любым OpenAI-совместимым сервером в вашей сети: Ollama, LM Studio, KoboldCpp, llama.cpp и т.п. Лимитов запросов нет, ключ не нужен, а какие ответы разрешены, определяет выбранная вами модель.

1. На ПК установите Ollama (или LM Studio) и скачайте модель.
2. Откройте доступ по сети:
   - **Ollama**: задайте переменные окружения `OLLAMA_HOST=0.0.0.0` и `OLLAMA_ORIGINS=*`, перезапустите Ollama и разрешите ему доступ в брандмауэре (порт 11434).
   - **LM Studio**: вкладка Developer → Server Settings → включите «Serve on Local Network» и «Enable CORS», запустите сервер (порт 1234).
   - **KoboldCpp**: запуск с `--host 0.0.0.0`, по умолчанию порт 5001.
3. Узнайте IP ПК в локальной сети (в Windows — команда `ipconfig`). Телефон и ПК должны быть в одной Wi-Fi сети.
4. В приложении: ⚙️ Настройки → выберите пресет (Ollama / LM Studio / KoboldCpp), замените IP в адресе → «Проверить подключение» → «Показать модели сервера» → выберите модель.

Если сервер запущен прямо на телефоне (например, в Termux), выберите пресет «Этот телефон» и укажите нужный порт. Для небольших локальных моделей уменьшите в настройках «Сколько последних сообщений помнить» (8–16): у них короткая память. В «Дополнительных параметрах» можно задать, например, `{"top_p": 0.95, "repeat_penalty": 1.1}`.

### Не из домашней Wi-Fi сети (Tailscale)

Чтобы пользоваться своим сервером из любой сети, в том числе по мобильному интернету, без открытия портов в роутере:

1. Установите [Tailscale](https://tailscale.com) на ПК и на телефон и войдите в один аккаунт (для личного некоммерческого использования тариф бесплатный).
2. Ollama или LM Studio настройте как для домашней сети (`OLLAMA_HOST=0.0.0.0` и т.д.).
3. Узнайте адрес ПК в Tailscale: он начинается с `100.`, виден в приложении Tailscale.
4. В РП Чате вместо IP из Wi-Fi впишите этот адрес, например `http://100.101.102.103:11434/v1`.

Tailscale должен быть включён на телефоне, а ПК — включён и не спать. **Не пробрасывайте порт Ollama в интернет через роутер и не публикуйте его через туннели без пароля:** у Ollama нет авторизации.

## Группы и каталог ботов (сервер сообщества)

Две вкладки внизу приложения — **Группы** и **Каталог** — работают через маленький сервер, который запускается на вашем компьютере. Сторонних сервисов и аккаунтов не нужно, данные лежат в одном файле у вас на диске.

- **Каталог**: опубликуйте своего персонажа (на вкладке «Персонажи» ⋮ → «Опубликовать в каталог»), и другие участники сервера смогут найти его (поиск, «Новые» / «Популярные») и добавить к себе. Обновить или снять с публикации можно там же. Публикация необязательна — по умолчанию все персонажи остаются только у вас.
- **Группы**: общий чат с друзьями и ботами. Создайте группу, выберите ботов из своих персонажей, отправьте друзьям **код приглашения** (⋮ → «Пригласить друзей»). Друзья входят через «Войти по коду», могут добавлять в группу и своих ботов.
  - Режим ответов: «Отвечают все боты» или «Только когда позвали». Позвать бота — `@имя` (или `@все`); кнопки-подсказки под чатом вставляют упоминания сами.
  - Сообщения приходят в реальном времени, видно, кто печатает; создатель группы может удалять чужие сообщения и ботов, любой участник — свои.

**Как отвечают боты.** Ответ бота генерирует телефон того, кто написал сообщение, с его настройками модели (ключ OpenRouter или свой сервер), а затем публикует ответ в группу. Поэтому тем, кто хочет «будить» ботов, нужна настроенная модель; читать и писать друг другу можно и без неё. Бот в группе работает по снимку карточки, добавленному в момент приглашения.

### Запуск сервера

Нужен [Node.js](https://nodejs.org) версии 18 или новее (больше ничего ставить не надо):

```bash
cd rp-chat
node server/server.mjs --invite МОЙ_КОД
```

Сервер напечатает адреса вида `http://192.168.0.100:8787` (Wi-Fi) и `http://100.x.x.x:8787` (Tailscale). Параметры (или переменные `RP_PORT`, `RP_HOST`, `RP_DATA`, `RP_INVITE`, `RP_ADMIN`):

| Флаг | Значение |
| --- | --- |
| `--invite КОД` | Код доступа: без него на сервере не зарегистрироваться. **Задайте обязательно**, если сервер виден кому-то кроме вас. |
| `--port 8787` | Порт. На Windows разрешите Node.js доступ в брандмауэре. |
| `--host 0.0.0.0` | На каком адресе слушать (по умолчанию все интерфейсы). |
| `--data файл.json` | Где хранить данные (по умолчанию `server/rp-server-data.json`). Это единственный файл — копируйте его для резервной копии. |
| `--admin ТОКЕН` | Токен модератора: с заголовком `X-Admin-Token` позволяет удалять записи каталога. |

В приложении: ⚙️ Настройки → **Сервер сообщества** → адрес, ник и код доступа → «Подключиться». Каждому участнику сервер выдаёт личный ключ доступа (в Настройках его можно показать и сохранить, чтобы войти под тем же ником с другого телефона).

**Друзья вне вашей сети.** Как и со своей моделью, самый простой путь — Tailscale: друг устанавливает Tailscale и получает доступ к вашему компьютеру (пригласите его в свою сеть или используйте «Share» для этой машины в админке Tailscale), после чего вводит в приложении адрес `http://100.x.x.x:8787`. Не пробрасывайте порт сервера в интернет через роутер: трафик не шифруется (внутри Tailscale он шифруется самим VPN), а защита — только код доступа.

Что видит сервер: ники, карточки опубликованных и добавленных в группы ботов и тексты сообщений групп. Хранятся они открытым текстом в файле данных, администратор сервера (то есть вы) может их прочитать. API-ключи моделей на сервер не отправляются никогда.

Лимиты: до 20 участников и 8 ботов в группе, 50 опубликованных ботов на участника, сообщение до 8000 символов, в группе хранится последние 5000 сообщений.

## Возможности

- Карточки персонажей: имя, аватар (эмодзи или картинка), описание, характер, манера речи и поведение, сценарий, первое сообщение, пример диалога, жёсткие правила. Макросы `{{char}}` и `{{user}}`.
- Чат с памятью (последние N сообщений), потоковый вывод, «Стоп», «Заново», «Продолжить», правка и удаление сообщений, откат диалога к выбранному месту, новый чат.
- Ваш персонаж в игре: имя и описание.
- Импорт карточек SillyTavern (`.json` и `.png`, форматы V1/V2/V3), экспорт и резервные копии.
- Настройки: температура, длина ответа, глубина памяти, дополнительные параметры JSON, адрес API (OpenRouter, свой сервер или любой OpenAI-совместимый, например `https://api.deepseek.com`).
- Ключ и модель запоминаются отдельно для OpenRouter и для своего сервера, поэтому ключ OpenRouter не уходит на локальный сервер.
- Групповые чаты с друзьями и ботами и общий каталог персонажей (см. раздел выше).
- Личные данные хранятся на устройстве; ключи моделей никуда, кроме выбранного API, не отправляются и в резервную копию не попадают. Если подключён сервер сообщества, на него уходит только то, что вы публикуете или пишете в группах.

## Как устроено

- `www/` — само приложение (чистый HTML/CSS/JS, без сборки): `lib.js` — логика промптов, импорта и групп, `api.js` — запросы к модели, `community.js` — клиент сервера сообщества, `app.js` и `groups.js` — интерфейс.
- `server/server.mjs` — сервер сообщества (только встроенные модули Node.js, данные в JSON-файле). В APK не входит.
- Capacitor оборачивает `www/` в Android-приложение. Папка `android/` не хранится в репозитории: workflow (`.github/workflows/rp-chat-apk.yml` в корне репозитория) генерирует её командой `npx cap add android`, накладывает иконки из `resources/` и собирает APK.
- `tests/` — тесты: `npm test` (логика, API-клиент, сервер и клиент сообщества на Node), `python3 tests/ui/ui_test.py` и `python3 tests/ui/groups_test.py` (интерфейс в headless Chromium; второй поднимает настоящий сервер и двух «пользователей»).

## Локальная разработка

```bash
npm test                           # юнит-тесты, API-клиент, сервер и клиент сообщества
npm run server -- --invite КОД     # запустить сервер сообщества локально
python3 -m http.server -d www 8080 # открыть http://localhost:8080 в браузере
```
